# EventHub

## Descripción

EventHub es una plataforma web para la administración de eventos. Permite a organizadores publicar eventos y a los asistentes registrarse, comprar entradas y acceder mediante códigos QR.

---

# Objetivo General

Desarrollar una plataforma web que facilite la organización, administración y asistencia a eventos mediante herramientas digitales.

---

# Objetivos Específicos

- Gestionar usuarios.
- Gestionar eventos.
- Gestionar entradas.
- Controlar asistencia mediante QR.
- Visualizar estadísticas.
